Supplementary material for:
Contradiction-Aware Mediative Fuzzy Logic: Operators, Semantic Coherence,
Type-2/Type-3 Extensions, and Quantum Semantics

Contents
--------
1. zod_selected_preprocessed_rows.csv
   Minimal preprocessed representation of the three ZOD-derived illustrative
   rows used in the manuscript. The file contains only the fields needed to
   reproduce the values reported in Table 2: split, frame identifier, risk
   indicator, reason/proximity field, contextual coding components, context
   score, distance when available, and the reported rounded values.

2. reproduce_zod_mfl.py
   Minimal Python script that recomputes c, D, r, mu_p, nu_p, pi_p, zeta_p,
   M(mu_p,nu_p), and the safety-biased decision category. It uses only the
   Python standard library.

3. zod_mfl_recomputed_results.csv
   This file is generated by the script after execution.

How to reproduce
----------------
Place the CSV and the Python script in the same folder and run:

    python reproduce_zod_mfl.py

The script writes:

    zod_mfl_recomputed_results.csv

and prints the rounded values reported in the manuscript.

Coding rules reproduced by the script
-------------------------------------
The context score is

    c = 0.35*c_weather + 0.25*c_light + 0.20*c_road + 0.20*c_density.

For positive-risk rows, distance is converted into

    D = clip(d/10, 0, 1),  r = 1 - D,

and the truth-falsity pair is

    mu_p = 0.55 + 0.35*r + 0.10*c,
    nu_p = 0.05 + 0.20*D + 0.25*c.

For non-risk rows,

    mu_p = 0.10 + 0.30*c,
    nu_p = 0.60 + 0.25*(1 - c).

Hesitation, contradiction, and the mediative score are

    pi_p   = max(0, 1 - mu_p - nu_p),
    zeta_p = max(0, mu_p + nu_p - 1),
    M      = (1 - pi_p - zeta_p/2)*mu_p + (pi_p + zeta_p/2)*(1 - nu_p).

Decision thresholds
-------------------
The script uses the manuscript thresholds:

    M >= 0.7       : decisive braking
    0.5 <= M < 0.7 : cautious deceleration and additional sensing
    M < 0.5        : cautious monitoring

Data note
---------
The rows are derived from preprocessed ZOD metadata and are intended only to
reproduce the illustrative mediative calculations in the manuscript. They do
not contain raw ZOD sensor data, images, LiDAR, radar, or personally identifying
information. The original Zenseact Open Dataset is cited in the manuscript.
