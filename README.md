# Supplementary Material for Contradiction-Aware Mediative Fuzzy Logic

Supplementary material for the manuscript:

**Contradiction-Aware Mediative Fuzzy Logic: Operators, Semantic Coherence, Type-2/Type-3 Extensions, and Quantum Semantics**

**Author:** Oscar Montiel Ross
**Year:** 2026

This repository contains the reproducibility material for the ZOD-derived safety-first Mediative Fuzzy Logic (MFL) illustrative case study reported in the manuscript.

The purpose of this repository is to make the illustrative real-world application transparent and reproducible. The files provided here reproduce the deterministic calculations used to obtain the contextual score, proximity quantities, mediative truth-falsity pairs, hesitation, contradiction, mediative scores, and safety-biased decision categories reported in the manuscript.

This repository does **not** train, validate, or benchmark an autonomous-driving perception model.

---

## Contents

1. `zod_selected_preprocessed_rows.csv`
   Minimal preprocessed representation of the three ZOD-derived illustrative rows used in the manuscript. The file contains only the fields needed to reproduce the values reported in the manuscript: split, frame identifier, risk indicator, reason/proximity field, contextual coding components, context score, distance when available, and the reported rounded values.

2. `reproduce_zod_mfl_notebook_v5.ipynb`
   Annotated Python notebook that explains, step by step, how the ZOD-derived mediative calculations are reproduced. It computes the contextual score, proximity quantities, mediative truth-falsity pairs, hesitation, contradiction, mediative score, and safety-biased decision category.

3. `reproduce_zod_mfl.py`
   Minimal Python script that recomputes the same quantities as the notebook:

   * contextual uncertainty score `c`;
   * distance and proximity quantities `D` and `r`;
   * mediative truth-falsity pair `(mu_p, nu_p)`;
   * hesitation `pi_p`;
   * contradiction `zeta_p`;
   * mediative score `M(mu_p, nu_p)`;
   * safety-biased decision category.

   The script uses only the Python standard library.

4. `zod_mfl_recomputed_results.csv`
   Recomputed output file generated by the script. It is included for convenience so that readers can directly inspect the reproduced numerical results.

5. `LICENSE`
   MIT License for the code and notebook in this repository.

## How to Run the Python Script

To reproduce the numerical results using the standalone Python script, place the following files in the same folder:

```text
zod_selected_preprocessed_rows.csv
reproduce_zod_mfl.py
```

Then run:

```bash
python reproduce_zod_mfl.py
```

The script writes:

```text
zod_mfl_recomputed_results.csv
```

and prints the rounded values reported in the manuscript.

The script uses only the Python standard library and does not require additional packages.

## How to Run the Notebook Locally

To run the notebook locally, first clone or download this repository.

Using Git:

```bash
git clone https://github.com/oross/contradiction-aware-mfl-zod-supplement.git
cd contradiction-aware-mfl-zod-supplement
```

The notebook uses `pandas` for tabular display and Jupyter for interactive execution. If needed, install them with:

```bash
python -m pip install pandas notebook
```

Then start Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```text
reproduce_zod_mfl_notebook_v5.ipynb
```

and run the cells from top to bottom.

Alternatively, if using JupyterLab:

```bash
python -m pip install pandas jupyterlab

```

Then open the notebook and run all cells.

## Coding Rules Reproduced by the Script and Notebook

The contextual uncertainty score is computed as:

```text
c = 0.35*c_weather + 0.25*c_light + 0.20*c_road + 0.20*c_density.
```

For positive-risk rows, distance is converted into:

```text
D = clip(d/10, 0, 1),
r = 1 - D.
```

The truth-falsity pair is then computed as:

```text
mu_p = 0.55 + 0.35*r + 0.10*c,
nu_p = 0.05 + 0.20*D + 0.25*c.
```

For non-risk rows:

```text
mu_p = 0.10 + 0.30*c,
nu_p = 0.60 + 0.25*(1 - c).
```

Hesitation, contradiction, and the mediative score are:

```text
pi_p   = max(0, 1 - mu_p - nu_p),
zeta_p = max(0, mu_p + nu_p - 1),
M      = (1 - pi_p - zeta_p/2)*mu_p + (pi_p + zeta_p/2)*(1 - nu_p).
```

## Decision Thresholds

The script and notebook use the decision thresholds reported in the manuscript:

```text
M >= 0.7        : decisive braking
0.5 <= M < 0.7  : cautious deceleration and additional sensing
M < 0.5         : cautious monitoring
```

These thresholds are used only for the illustrative safety-first decision scenario.
